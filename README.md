# Environment Monitor

Sistema para monitoramento de ambientes corporativos.

## Objetivo

O projeto tem como objetivo monitorar a disponibilidade dos ambientes utilizados pela equipe de QA, permitindo identificar rapidamente indisponibilidades em aplicações Web, Banco de Dados, Coletores e Middleware.

---

## Tecnologias

- Java 21
- Spring Boot 4
- React
- Maven
- Oracle
- SQL Server
- Microsoft Teams Webhook
